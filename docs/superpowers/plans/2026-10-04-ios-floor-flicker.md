# iOS-Bodenflackern

Ziel: stabiles Bodenbild ohne Änderung der Navigation oder Aufgaben.

1. Koplanare Bodenflächen und ungefiltertes perspektivisches Raster gezielt untersuchen.
2. Unterbau geometrisch vom Boden trennen und nachgewiesenes Raster-Aliasing im Shader filtern.
3. WebGL-Prüfung, vorhandene Tests, Build und unabhängige Codeprüfung durchführen.
4. Autorisiert auf GitHub Pages veröffentlichen und Live-Assets prüfen.

Ein physisches iOS-Gerät steht hier nicht zur Verfügung; Browserprüfungen werden entsprechend bezeichnet.
