# Cyberpunk To-do-Liste Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Eine mobile-first To-do-Liste mit Cyberpunk-Anmutung und isometrischer 8-Bit-Grafik starten.

**Architecture:** Eine lokale React-App mit einer Aufgabenansicht, einem separaten Speicher-Modul und einer lokalen SVG-Grafik. Vite liefert Entwicklungsserver und Produktionsbuild; Tailwind übernimmt Layout und Styling.

**Tech Stack:** Vite, React, Tailwind CSS mit Vite-Plugin, JavaScript, SVG.

**Spec:** `docs/superpowers/specs/2026-10-04-todolist-design.md`

## Global Constraints
- Deutsche Oberfläche, kein Login und kein Datenserver.
- Aufgaben hinzufügen, abhaken, wieder öffnen, löschen und filtern.
- Speicherung in localStorage; ungültige gespeicherte Daten führen zu einer leeren Liste.
- Mobile first ab 320 Pixel Breite; Bedienelemente mindestens 44 Pixel hoch.
- Cyberpunk-Anmutung und eine lokale isometrische 8-Bit-Stadtszene.
- Start mit leerer Liste; keine vorgefertigten persönlichen Aufgaben.

## Review Focus
- Leerzeichen-Eingaben: keine leeren Aufgaben erzeugen.
- Sehr lange Aufgabentexte: umbrechen, ohne Bedienelemente zu verdrängen.
- Ungültige gespeicherte Daten: App bleibt bedienbar.
- Blockierter Browser-Speicher: Aufgaben funktionieren im Tab mit Hinweis.
- Tastatur und schmale Bildschirme: alle Aktionen erreichbar, kein horizontales Scrollen.

**Interfaces:** `loadTasks(storage) -> { tasks, warning }` und `saveTasks(storage, tasks) -> boolean`; Aufgaben haben `id: string`, `text: string`, `completed: boolean`.
